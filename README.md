# Paper Quick Report

**用 Codex 快速阅读论文，提炼核心贡献、实验依据和适用范围。**

给 `paper-quick-report` 一份本地 PDF 或可访问的论文链接，就能得到一份结构化速读报告。报告用一句话概括核心贡献，再说明作者要解决的问题、方法的工作流程、哪些实验支撑主要结论，以及这篇论文对后续工作有什么参考价值。

适合筛选待读论文、建立组会前的阅读笔记，或快速理解预印本、基准评测论文和技术稿件。报告默认使用请求的语言，通常包含 6–10 段短文或要点。

## 安装

需要一个可用的 Codex 环境。这个 skill 由 Markdown 指令和界面元数据组成，无需为它安装独立的软件包。

**个人使用**可将仓库克隆到 Codex 的用户级 skills 目录。

```bash
mkdir -p "$HOME/.agents/skills"
git clone https://github.com/zhushiL/paper-quick-report.git "$HOME/.agents/skills/paper-quick-report"
```

**项目内共享**可将 skill 目录放到目标项目的 `.agents/skills/paper-quick-report/` 下。安装后，`SKILL.md` 应直接位于 `paper-quick-report/` 目录内。如果 Codex 没有显示该 skill，可以重启后再试。[Codex 官方 skills 文档](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)

## 快速上手

在 Codex 中调用 `$paper-quick-report`，同时提供附件、本地 PDF 路径或论文链接。

**本地 PDF**

```text
用 $paper-quick-report 阅读 ./papers/example.pdf，给我一份中文速读报告。
```

**arXiv 论文**

```text
用 $paper-quick-report 阅读这里的论文：[粘贴 arXiv 链接]。
重点说明论文的研究问题、核心方法和支撑主要结论的实验。
```

**具身智能或机器人论文**

```text
用 $paper-quick-report 总结附件。分别说明仿真与实机实验，列出任务设置、
对照方法和关键成功率，并指出哪些消融能支持作者的设计选择。
```

可以在请求里指定语言、篇幅、格式或重点。在支持自动匹配的 Codex 环境中，「快速总结这篇论文」这类请求也可能触发该 skill。[Codex 官方调用说明](https://learn.chatgpt.com/docs/build-skills#how-chatgpt-and-codex-use-skills)

## 报告长什么样

报告顶部单独展示论文原标题，下方八个部分各用一行 Markdown 三级标题（`###`）。机构或日期缺失时标注「未在论文中找到」。

```markdown
## 论文原标题

我读的是 [论文 PDF](论文路径或链接)。

### 论文信息

- 作者：…
- 机构：…
- 发表场所和日期：…
- 页数：…

### 一句话概括

用一句话交代核心贡献和它的意义。

### 核心问题

指出论文针对的瓶颈、研究空白或待验证的假设。

### 方法

先说明方法的核心思路，再按顺序讲清输入经过哪些步骤、最后得到什么输出。

解释关键模块的作用和衔接方式，并说明主要设计如何解决论文提出的问题。按需补充训练数据、训练目标或推理流程。对于实证研究或基准论文，说明研究设计和评测过程。

### 关键实验结果

说明任务设置与对照方法，给出成功率等关键数字，并说明相关消融回答了什么问题。

### 最重要的洞见

提炼结果揭示的规律、设计启示或得到修正的假设。

### 局限

交代作者指出的局限，以及任务覆盖、硬件依赖、泛化等证据边界。

### 我的判断

说明论文的贡献类型、实际参考价值和值得继续关注的问题。
```

## 阅读流程

1. **核对来源和正文。** 记录论文信息，依次阅读摘要、引言、方法、实验、局限和结论，找出论文要回答的具体问题。
2. **结合图表核对证据。** 使用环境提供的 PDF 工具提取文本，并查看重要图表和图注。遇到扫描件、双栏错序或关键表格提取不全时，渲染并查看相关页面。
3. **提炼方法和关键结果。** 保留准确的模型名、任务名和实验数字，优先选取能支撑主张的对照或消融。论文同时包含仿真和实机实验时，分别说明两者的设置与结果。
4. **标明结论的来源。** 用「作者认为」「论文显示」「我的判断是」等表述区分论文主张、实验观察和阅读判断，并说明证据能支持多大范围的结论。
